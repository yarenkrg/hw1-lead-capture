# Lead Capture Project (HW1 & HW2)

This repository contains the implementations of HW1 and HW2 assignments.

## HW1
A basic data pipeline that captures user input, processes it, and stores it in Google Sheets. It also includes a simulated AI response.

## HW2
An improved version of the pipeline that accepts POST requests via webhook and directly stores the data in Google Sheets without manual entry.

## Technologies Used
- n8n
- Webhook API
- Google Sheets
